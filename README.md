## Featured projects

**[IT Equipment Inventory System](https://github.com/ErikAboytes/inventario-ti-tersa)** · React, TypeScript, PostgreSQL (Supabase), Python

Web system that will replace an Excel-based inventory of computer equipment.
- Role-based access control with Row Level Security.
- Business rules enforced in the database: trigger-based state transitions, atomic check-outs with row locking, gap-free document numbers and an automatic audit log.
- Python ETL that cleans and reconciles the legacy Excel data.
- Printable custody letters, QR labels and mobile QR scanning.
- 130 unit tests (Vitest), E2E and accessibility tests (Playwright, axe-core).
- Status: approved for production; deployment to AWS EC2 with Docker underway.

**[Fake-Radar](https://github.com/Elteclass/Fake-Radar)** · Python, FastAPI, Pydantic, Gemini API

Academic team project (8 members): a fake-news detector with a web app and a Chrome extension. As a backend team member, I [migrated the Gemini integration to the google-genai SDK and enabled Google Search grounding](https://github.com/Elteclass/Fake-Radar/pull/26), so each analysis cites real sources.
